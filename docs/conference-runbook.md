# Conference Runbook

## Before event
1. Confirm production event configuration is locked.
2. Load and approve all questions; verify media.
3. Assign exact questions to rounds; confirm no duplicates.
4. Rehearse Demo Mode end-to-end.
5. Test participant devices/network, Control Room, projector and backup control device.
6. Confirm projector audio for video questions.
7. Verify admin 2FA and Live Control Lock.
8. Export a configuration snapshot before opening registration.

## During event
- Monitor participant progress and Integrity Monitor.
- Use Control Room for all round state changes.
- Do not edit competition configuration casually after registration opens.
- Void flawed questions using the approved void flow.
- For system-wide outage, place the round into protected state and follow recovery procedure.
- Use Take Control only after confirming the current controller is unavailable.

## Final
- Confirm Top 10 finalists.
- Run the 10-question final.
- Apply deterministic tie-breaks and sudden death where required.
- Reveal winner through Projector.

## After event
- Freeze event.
- Generate participant/question-performance reports.
- Review integrity and audit logs.
- Apply configured retention/deletion policy.
- Archive the event.
